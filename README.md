## Overview

AI_NEET is an offline AI platform that converts NCERT textbooks and NEET previous-year papers into a structured, searchable knowledge base.

The system combines:

- OCR
- SQLite
- Local LLM (Ollama)
- AI Knowledge Extraction
- AI Question Extraction
- Document Assembly
- Future RAG Pipeline

Everything runs locally.
